# Decisions

One file per decision: `NNNN-short-title.md`, numbered in order.

Keep them short - context, the choice, the consequences we accepted. A decision
record exists so a future teammate (or agent) does not silently undo a choice
without knowing what it cost.

Decisions are append-only. To reverse one, add a new record that supersedes it.
